# Creating a file in OneDrive

## OneDrive

1. In Microsoft Edge, navigate to **https://www.office.com**.
1. In Microsoft 365 Copilot, click the *App launcher* icon (the waffle icon) next to **Copilot**, and click **OneDrive**.

    *Note:* OneDrive opens in a new browser tab. If a message about Copilot in OneDrive appears, click **Not now**.
1. In OneDrive, in the toolbar, click **New**, and click **Word document**.
1. In Word for the web, click the document title, type **\<file name\>**, and press **Enter**.

    Verify that the file **\<file name\>** is listed in the root folder of OneDrive.

1. In Word for the web, click the **Back** icon in the upper-left corner to return to OneDrive.
