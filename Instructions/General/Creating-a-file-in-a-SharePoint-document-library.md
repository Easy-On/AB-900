# Creating a file in a SharePoint document library

## SharePoint

1. In Microsoft Edge, navigate to **https://\<your tenant\>.sharepoint.com/sites/\<site address\>**.
1. On the home page of the site, in the navigation pane, click **Documents**.
1. In Documents, in the toolbar, click **New**, and click **Word document**.

    *Note:* Word for the web opens in a new browser tab.

1. In Word for the web, click the document title, type **\<file name\>**, and press **Enter**.
1. In Word for the web, click the document body, and type **\<text\>**.

    *Note:* Word for the web saves the document automatically.

1. Close the browser tab of Word for the web.
1. On the tab Documents, refresh the page.

    Verify that the file **\<file name\>** is listed in the document library.
