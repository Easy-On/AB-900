# Choosing the response mode in Microsoft 365 Copilot Chat

## Microsoft 365 Copilot Chat

1. In Microsoft Edge, navigate to **https://copilot.cloud.microsoft**.
1. In Microsoft 365 Copilot, click **New chat**.
1. Above the field **Message Copilot**, click the drop-down list next to **Work**, which shows **Auto** by default.

    Verify that the list shows the modes **Auto**, **Quick response**, and **Think deeper**.

1. Select **\<mode\>**, for example **Quick response**.

    Verify that the drop-down list shows **\<mode\>**.

1. Click the field **Message Copilot**, wait two seconds, type **\<prompt\>**, and press Enter.

    Verify that Copilot shows an answer. Note how long the answer takes and how detailed it is.

*Note:* **Auto** lets Copilot decide how long to think. **Quick response** answers right away. **Think deeper** takes longer for better answers.
