# Creating a SharePoint agent

## SharePoint

1. In Microsoft Edge, navigate to **https://\<your tenant\>.sharepoint.com/sites/\<site name\>**.
1. On the home page of the site **\<site name\>**, click **New**, **Agent**.

    *Note:* If the message Start designing your site appears first, click **Maybe later**. You can also create an agent from a document library. In the document library, on the command bar, click **Create an agent**.

1. In Create your new agent, on the tab Overview, select the text in the field **Name**, and type **\<agent name\>**.
1. Under **Purpose**, keep the proposed text, or replace it with **\<agent description\>**.
1. Click the tab **Behavior**.
1. On the tab Behavior, under **Agent instructions**, select the text, and type **\<agent instructions\>**.

    Verify that the agent preview on the right shows **\<agent name\>**.

1. Click **Create agent**.

    Verify that the message Your agent is ready to use is shown. The agent is saved as the file **\<agent name\>.agent** in the document library of the site.

1. In the message, click **Chat with agent**.

    Verify that the agent chat pane opens with the name **\<agent name\>** at the top.

1. In the agent chat pane, click the prompt box, type **\<test prompt\>**, and press **Enter**.

    Verify that the agent answers the prompt with content from the site.

*Note:* To create an agent, you need Edit permissions on the site. By default, the agent uses the entire site as its source. To change the sources, use the tab Sources.
