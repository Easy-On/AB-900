# Applying a sensitivity label to a file

## OneDrive

1. In Microsoft Edge, navigate to **https://www.office.com**.
1. In Microsoft 365 Copilot, click the *App launcher* icon (the waffle icon) next to **Copilot**, and click **OneDrive**.

    *Note:* OneDrive opens in a new browser tab. If a message about Copilot in OneDrive appears, click **Not now**.
1. In OneDrive, in the navigation pane, click **My files**.
1. In My files, find the file **\<file name\>** and select the check box next to it.
1. In the upper-right corner of the command bar, click **Details**.
1. In the details pane, under **Properties**, click the field under **Sensitivity**, and in the drop-down list select **\<label name\>**.

    *Note:* If **\<label name\>** is not in the list, the label is not yet available. A published label can take about an hour, and up to 24 hours, to appear. Reload the page after some time.

1. Click an empty area of the details pane.

    Verify that the field **Sensitivity** shows **\<label name\>**, also after you reload the page.

## Word for the web

1. In Microsoft Edge, navigate to **https://www.office.com**.
1. In Microsoft 365 Copilot, click the *App launcher* icon (the waffle icon) next to **Copilot**, and click **OneDrive**.

    *Note:* OneDrive opens in a new browser tab. If a message about Copilot in OneDrive appears, click **Not now**.
1. In OneDrive, click the file **\<file name\>** to open it in Word for the web.
1. In Word for the web, on the tab Home, click **Sensitivity**, and select **\<label name\>**.

    Verify that the label **\<label name\>** is shown next to the file name in the title bar.

*Note:* A label is available for a file only after the label has been published. A published label can take up to 24 hours to appear. Sensitivity labels must be enabled for files in SharePoint and OneDrive.
