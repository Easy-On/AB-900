# Creating a Copilot Chat agent

## Microsoft 365 Copilot Chat

1. In Microsoft Edge, navigate to **https://copilot.cloud.microsoft**.
1. In Copilot, in the navigation pane, click **Agents**, and click **New agent**.
1. In Build your own specialist agent, click the prompt box **Message Agent Builder**, type **\<agent description\>**, and press **Enter**.

    Verify that Agent Builder shows a draft of the agent with a name and instructions. Creating the draft takes about 20 seconds.

1. In the chat pane of Agent Builder on the left, click the prompt box **Message Agent Builder**, type **Rename the agent to \<agent name\>.**, and press **Enter**.

    Verify that the draft shows the name **\<agent name\>**.

    *Note:* You cannot change the name of the draft directly. Use the chat pane to change it.

1. In Agent Builder, in the upper-right corner, click **Create**.

    Verify that the message Your agent was created successfully is shown. The agent is private, which means that only you can use it.

1. In the message, click **Start chat**.

    Verify that the name **\<agent name\>** is shown above the prompt box.

1. In the prompt box, type **\<test prompt\>**, and press **Enter**.

    Verify that the agent answers the prompt.

*Note:* The agent is listed under **My agents** on the page New agent, and in the Microsoft 365 admin center under **Agents**, **All agents**.
