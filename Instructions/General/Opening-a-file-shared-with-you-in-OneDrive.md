# Opening a file shared with you in OneDrive

## OneDrive

1. In Microsoft Edge, navigate to **https://www.office.com**.
1. In Microsoft 365 Copilot, click the *App launcher* icon (the waffle icon) next to **Copilot**, and click **OneDrive**.

    *Note:* OneDrive opens in a new browser tab. If a message about Copilot in OneDrive appears, click **Not now**.
1. In OneDrive, in the navigation pane, click **Shared**.
1. In Shared, check that the tab **With you** is selected.

    Verify that **\<file name\>** is listed with the name of the person who shared it.

1. Click **\<file name\>**.

    Verify that the file opens in the app for the web, for example Word for the web. If you have the permission **Can view**, the file opens in the mode Viewing, and you cannot switch to Editing.

    *Note:* If the message Your privacy options appears, click **Close**. If the file has a sensitivity label, the title bar shows a shield icon. Point to the icon to see the name of the label.

*Note:* You can also open the file with the link in the sharing email in Outlook.
