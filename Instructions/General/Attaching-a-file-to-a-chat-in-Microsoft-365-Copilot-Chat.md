# Attaching a file to a chat in Microsoft 365 Copilot Chat

## Microsoft 365 Copilot Chat

1. In Microsoft Edge, navigate to **https://copilot.cloud.microsoft**.
1. In Microsoft 365 Copilot, click **New chat**.
1. Click the *Plus* icon (the **+** icon) to the left of the field **Message Copilot**, and click **Attach cloud files**.
1. In the file picker, on the page Home, click **\<file name\>**, and click **Select**.

    Verify that the file **\<file name\>** is shown above the field **Message Copilot**, and that Copilot offers suggested prompts for the file.

1. Click a suggested prompt, for example **Make suggestions for \<file name\>**, or type **\<prompt\>**, and click the *Send* icon (the arrow icon) to the right of the field.

    *Note:* A suggested prompt is only inserted into the field. You must click the *Send* icon to send it.

    Verify that the answer refers to the content of the file **\<file name\>**.

*Note:* To use a file from your computer, click **Upload images and files** instead of **Attach cloud files**.
