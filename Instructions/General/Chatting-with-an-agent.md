# Chatting with an agent

## Microsoft 365 Copilot Chat

1. In Microsoft Edge, navigate to **https://copilot.cloud.microsoft**.
1. In Copilot, in the navigation pane, under **Agents**, click **\<agent name\>**.

    *Note:* If the agent is not listed, click **All agents**, and find and click **\<agent name\>**.

    Verify that the name of the agent is shown above the prompt box.

1. In the prompt box, type **\<prompt\>**, and press **Enter**.

    Verify that the agent shows a response to the prompt.

1. Repeat the previous step for each further prompt.

## SharePoint

1. In Microsoft Edge, navigate to **https://\<your tenant\>.sharepoint.com/sites/\<site name\>**.
1. On the home page of the site **\<site name\>**, in the top-right corner, click the *Copilot* icon.
1. In the agent chat pane, click the agent selector at the top, and click **\<agent name\>**.

    Verify that the name of the agent is shown at the top of the agent chat pane.

1. In the prompt box, type **\<prompt\>**, and press **Enter**.

    Verify that the agent shows a response to the prompt.

1. Repeat the previous step for each further prompt.

*Note:* An agent answers only with the data that your account is allowed to access. A response can take a few seconds.
