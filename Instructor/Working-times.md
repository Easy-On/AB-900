# Working times of practices and labs

The table shows the pure working time for each practice and lab. The working time is the time that was needed to perform the steps in the online lab environment, without waiting for inputs, sign-ins, or sessions. Plan the course with the last column.

* **Measured working time:** The time of one run. Some values are estimates and are marked with *approx.*
* **With 50 % buffer:** The measured working time plus 50 %, because participants need more time than a run that already knows the steps.
* **Planning time:** The value with the buffer, rounded to 5 minutes, with a minimum of 5 minutes.
